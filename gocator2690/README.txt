++++++++++++++ README +++++++++++++++++++++++++++

The zip file contains the following files:

1. Gocator_2690.STEP

CAD model of the sensor in STEP format. STEP files can be 
imported into nearly all modern CAD packages. The files contain
not only sensor dimensions, but also information for the line of
sight and field of view (FOV) of this sensor.

2. Gocator_2690_Drawings_2D.pdf

PDF file that contains drawings and dimensions of the sensor in 6
different views (front, back, top, bottom, left side, right side). 
This file can be opened by all common PDF viewers.

3. Gocator_2690_Drawings_3D.pdf

PDF file containing a 3D model of the sensor that can be  contains 
not only sensor dimensions, but also information for the line
of sight and field of view (FOV) of this sensor. This file can be opened
by PDF viewers that support 3D pdf (recommended viewer is Acrobat
Reader - http://get.adobe.com/reader).

4. Gocator_2690.SLDPRT

CAD model of the sensor in simplified Solidworks format. The files
contain not only sensor dimensions, but also information for the line
of sight and field of view (FOV) of this sensor.

5. Gocator_2690.X_T

CAD model of the sensor in PARASOLID format. The files contain
not only sensor dimensions, but also information for the line of
sight and field of view (FOV) of this sensor.

6. README.txt

The file that is currently being read. It contains information the
various CAD and drawing files contained in the zip package.
