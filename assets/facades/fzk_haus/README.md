# FZK-Haus IFC Sample

`AC20-FZK-Haus.ifc` is a small, widely-used public IFC4 test building (KIT/IfcOpenShell
reference "FZK-Haus": a two-storey single-family house, ~12m x 10m footprint) used here to
validate the IFC import pipeline end to end before pointing it at real facade BIM data.

## Files

- `AC20-FZK-Haus.ifc`: the source IFC file.
- `convert_fzk_haus.py`: extraction + USD conversion script (repeatable).
- `fzk_haus_extracted.json`: walls/windows/doors/levels/materials/units, generated by
  `gridsim_ifc.extract_ifc` (see `src/gridsim_ifc/extract.py`).
- `fzk_haus_visual.usd`: one triangulated `UsdGeom.Mesh` per wall/window/door/roof, generated by
  `gridsim_ifc.usd_export.build_ifc_usd`, grouped under
  `/World/ifc_facade/{walls,windows,doors,roofs}/<sanitized_guid>`.

## Regenerating

```bash
conda run -n base python assets/facades/fzk_haus/convert_fzk_haus.py
```

Requires `ifcopenshell` (extraction) and `usd-core`/`pxr` (USD conversion) in that environment
— see the root `README.md` "IFC facade import" section for the full environment split.

## Notes On Extraction

- Units: this file's `IfcUnitAssignment` is already metres (`scale_to_m = 1.0`), but
  `extract_ifc` always applies `ifcopenshell.util.unit.calculate_unit_scale` generically, so
  millimeter-based IFC exports convert correctly too.
- Exterior/interior walls: this file's `Pset_WallCommon` never sets `IsExternal` (common with
  some ArchiCAD exports). `_is_external` falls back to a name heuristic (`Wand-Ext-*` /
  `Wand-Int-*` → "ext"/"int" keyword match) when the property is absent, and only returns `None`
  if neither the property nor the name resolves it.
- Levels: 2 storeys — `Erdgeschoss` (ground floor, 0.0m) and `Dachgeschoss` (attic, 2.7m).
- Roofs: this file has no `IfcRoof` entity — the roof is 2 `IfcSlab` elements with
  `PredefinedType == ROOF` ("Dach-1"/"Dach-2"). `_is_roof_slab` checks that, falling back to a
  name hint ("Dach"/"roof") for files that leave `PredefinedType` unset.

## Visualizing In Isaac

```bash
./isaac/view_ifc_facade.sh
```

Defaults to referencing `fzk_haus_visual.usd`; pass `--ifc-usd <path>` for a different
converted asset.
